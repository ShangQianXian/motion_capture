# v0.2：素材对照预览与确认应用

适用 Windows、Blender 4.5.0、单人图片或视频。安装与模型配置沿用 [INSTALL.md](INSTALL.md)。本版不播放音频，不新增模型或手工关键点编辑；历史任务和 A/B 对比留待后续。

## 使用流程

1. 在 Mocap 侧栏的「素材与生成」选择文件。缩略图与媒体信息异步加载，不需要模型或 CUDA；需要 Preview worker 中的 OpenCV。图片隐藏视频播放和时序处理控件。
2. 选择模型档位并生成动作。MediaPipe 档位显示为「快速捕捉」，「对照预览」是所有档位共用的核对功能。
3. 完成后结果自动成为当前场景的待核对结果，打开对照预览。左边显示原素材与实际二维检测点，右边显示最终处理后的三维骨架。没有手部检测时不叠加手部识别结果。
4. 视频用独立时间轴播放、暂停、拖动、前后逐帧，支持循环以及 1×、0.5×、0.25×。空格播放，左右方向键逐帧；右侧中键旋转、滚轮缩放，按钮切换正面、侧面或复位。Esc 关闭并恢复三维视图。
5. 青色为人物左侧，橙色为右侧，红色表示低置信度。时间轴标记漏检、低置信度和插值帧，可在侧栏跳转问题帧。阈值沿用 0.4，不代表准确率。MotionBERT 的脚趾为估算关节，用灰色单独标注。
6. 镜像和倾斜立即更新三维预览；二维识别点始终保持原始检测含义。平滑、足底锁定、根运动、抽帧或捕捉档位改变后，需重新生成。
7. 选择所属场景的有效 Rigify Human 生成 rig，点击「确认并应用」。按钮在当前结果显示过且素材与参数匹配时开放。新的独立 Action 从第 1 帧开始；原 Action 保留。视频按场景实际帧率写入小数帧关键帧，图片仅生成第 1 帧姿态。应用时显示进度，Esc 取消，Ctrl+Z 撤销。

预览不会推动场景时间轴、创建场景骨架或创建 Action。缓冲时两侧停在同一源帧，素材帧到达后一起切换。慢解码可能延长预览播放时间，写入 Action 的速度始终按素材时间计算。

## 状态与恢复

- 更换素材、重新生成或改变捕捉参数会立即使旧结果失去应用资格；改回参数也需要重新生成。
- 结果按场景隔离；运行任务完成后只更新发起它的场景。撤销/重做后需要重新打开预览核对。
- 素材丢失时使用「重新定位素材」，以文件大小及修改时间核对同一素材。选择不同内容请重新生成；匹配恢复后再预览。
- 「开发工具 → 加载已有结果」选择 `mocap_result.json`。v0.1 文件可显示三维，明确提示无二维检测数据。新结果的 sidecar 损坏或与结果不匹配时拒绝加载。
- 关闭预览、切换文件、切换场景、载入 blend 或禁用插件会回收对应解码进程、绘制回调和临时图像。侧栏可重新建立一个缩略图，读取结束即关闭解码进程。
- 环境正常时诊断折叠；错误显示修复入口。详细日志、Mock 和高级烘焙保留在折叠区。

## 数据与开发接口

三维 `mocap_result.json` 保持 v0.1 格式。旁边的 `preview_manifest.json` 版本为 `0.2`，包含任务 ID、三维文件 SHA256、素材路径/大小/修改时间、分辨率、实际 FPS、输入与捕捉参数快照、检测拓扑和连线。每个采样帧保留零基 `source_index`、素材绝对时间 `time`、`sample_frame`、可为空的 `result_frame`、`body2d`、`hands2d` 和质量标记；漏检不删除记录。

二维点为 `[归一化 x, 归一化 y, confidence]`，原点在图像左上。MediaPipe 保留实际归一化点；MMPose 原图坐标除以实际解码尺寸。点可在画面外，绘制裁切而不扭曲坐标。三维预览与重定向共享 `core.preview.corrected_result` 的倾斜后镜像变换。

独立 `media_preview` 作业走外部 worker 的 stdin/stdout JSONL。请求为 `{"command":"frame","request_id":7,"source_index":42}`；另有 `probe` 和 `close`。响应 `media_info` / `media_frame` / `media_error` 带请求 ID，帧响应返回缓存路径和实际源帧编号。解码前合并取帧请求，Blender 仅接纳当前请求且源帧完全匹配的返回。

预览最长边 960 像素；Blender 图像缓存按 CPU/GPU 保守估计限 64 MiB；专用可重建 JPEG 磁盘缓存限 512 MiB。精确取帧使用源帧编号，播放与 Action 时间使用时间戳。视频 Action 关键帧为 `1 + (素材时间 - 采样起始时间) × (scene.render.fps / fps_base)`，保持场景帧率。

绘制基于 Blender 的 `SpaceView3D.draw_handler_add`、GPU builtin `IMAGE` / `UNIFORM_COLOR`、`batch_for_shader` 和 `blf`。不使用场景对象模拟预览。GPU 接口参考 [Blender 4.5 文档](https://docs.blender.org/api/4.5/gpu.types.html)。
