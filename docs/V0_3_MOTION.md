# v0.3 通用动作保真增强

面向 Windows、Blender 4.5、RTX 4060 8 GB。走路、跑步、攻击、待机共用捕捉链路，混合片段使用“通用／混合”。图片只恢复一帧姿态，跳过时序预设。

## 使用

1. 选择图片或视频，检查缩略图、分辨率、时长及实际帧率。
2. 选择模型档位和动作类型。模型决定检测／恢复能力，动作类型只调整后处理。
3. 生成后打开对照预览。左侧始终是原始二维检测；右侧用“原始／处理后”排查错误来自模型还是处理。
4. 视频两侧同步播放、逐帧、慢放。时间轴下两条细带依次表示左／右脚：绿色支撑、蓝色离地、灰色未知；红色时间轴标记需要核对的帧。
5. 核对处理后动作，必要时调整镜像、倾斜。平滑、锁脚、模型、动作类型和素材改变后需重新生成。原始诊断阶段不能直接确认应用。
6. 选择有效 Rigify Human 生成 rig，点击“确认并应用”。新 Action 从第 1 帧开始，以素材相对时间乘场景实际 FPS 写入小数帧。原 Action 保留；失败、取消回滚；支持撤销。

## 预设

| 动作类型 | 对称平滑窗口 | 最大短缺口 | 处理重点 |
|---|---:|---:|---|
| 通用／混合 | 约 0.10 秒 | 0.20 秒 | 保守处理，无周期假设 |
| 走路 | 约 0.15 秒 | 0.20 秒 | 可信支撑、离地释放，不强制交替 |
| 跑步 | 约 0.10 秒 | 0.20 秒 | 允许双脚离地，保留快速运动 |
| 攻击 | 约 0.067 秒 | 0.10 秒 | 高速、急停处减少平滑，保留蓄力与收势 |
| 待机 | 约 0.20 秒 | 0.20 秒 | 高频去抖，保留呼吸与缓慢重心变化，接触需持续可信 |

窗口按实际采样时间换算为奇数邻域；二次拟合至少使用 5 点，因此低采样率下的实际窗口会更长。高速和急变点直接保留，不跨长缺口拟合。支撑事件数只在走路、跑步诊断中提供，它不是人工确认的步数或准确率。

## 模型与安装

保留快速捕捉（MediaPipe）、Quality、Quality Plus。新增“身体与脚部增强”使用 RTMDet-m Person、RTMPose-m WholeBody、MotionBERT，复用 Quality worker 环境，不增加新三维模型。

```powershell
.\tools\download_models.ps1 -Profile quality_feet
.\.venv\Scripts\python.exe -m backend_worker.cli --check-env --profile quality_feet
```

WholeBody 输出 133 个二维点，本版只显示身体和脚部 23 点。脚趾、脚跟二维点用于接触证据与有限的图像平面方向约束，脚部深度仍为估计；不恢复三维脸部、精确手指、武器轨迹或握持。

配置固定 MMPose v1.3.2，权重链接固定在模型清单。新增档位缺少模型会报错，不静默替换。使用自定义 `models/manifest.json` 的用户需加入新条目，或移走自定义清单使用插件示例清单；不要覆盖已有模型文件。权重与运行时不随插件 ZIP 分发。许可状态见 [LICENSES.md](LICENSES.md)，未标注商业授权已确认。

## 素材准备

- 全身、双脚、手臂尽量保持可见，固定镜头，减少运动模糊。跑步、攻击优先使用原始较高帧率，避免为了省时过度抽帧。
- 侧前方素材通常有助于核对前后摆腿和膝盖弯曲；纯侧面容易让左右肢体相互遮挡。新的单路视频可直接输入，无需修改流程。
- 保留攻击的蓄力和收势、跑步的落地和腾空、待机的完整呼吸周期；不要只截一个代表姿态。
- 裁剪区间仍按现有“采样帧”编号填写。MotionBERT 额外读取前后最多 121 个采样帧作上下文，只输出所选范围。
- 风格化角色、遮挡、非人体比例会影响现有模型。若二维已错，后处理不能补回真实动作；若二维正确而原始三维错误，降低平滑也不能解决深度恢复问题。

## 数据与算法边界

`mocap_result.json` 保持旧格式，含最终三维；`mocap_raw.json` 保存模型阶段三维；`preview_manifest.json` 保持可选扩展兼容旧结果，增加：

- `stages.raw` 文件名及 SHA256、`raw_result_frame` 对应关系；
- `motion_type`、`processing_version`、`coordinate_space`、完整采样记录；
- `feet2d`、`joint_sources`、`contact_states`、插值／不可靠标记；
- `diagnostics` 中各关节幅度、延迟、接触区间，以及可用时的 CUDA 显存峰值。

三维坐标按整个序列固定平移估计地面，停止逐帧“最低脚贴地”。从可信三维估计固定肢体骨长，以末端轨迹求解膝盖／肘部，必要时有限调整骨盆以保持腿可达。骨盆校正属于运动学估计。根相对结果只限制可信支撑脚高度，不把向后的支撑脚运动锁死为世界固定点；有真实世界坐标的数据才使用世界位置锁脚。

现有单目链路没有可靠世界水平轨迹，默认不会添加前进运动掩盖姿态问题。真实腾空高度和被遮挡肢体仍有歧义。幅度保留指标比较处理前后，不代表对上传视频的识别准确率。
